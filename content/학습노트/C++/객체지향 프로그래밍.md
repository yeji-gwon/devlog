#### 1. 객체지향 프로그래밍(OOP, Object Oriented Programming)

- 정의
  데이터(멤버 변수)와 그 데이터를 처리하는 함수(멤버 함수)를 하나의 객체로 묶어서 프로그램을 설계하는 프로그래밍 패러다임
- 핵심 아이디어
	- 객체는 자신의 데이터와 행동(함수)를 스스로 **책임짐**→ 캡슐화
	- **복잡한 내부는 감추고** 필요한 것만 노출함 → 추상화
	- 객체 간의 관계(상속)를 통해 코드를 **재사용하고 확장함** → 상속
	- **같은 인터페이스**로 다양한 객체가 **서로 다르게 동작함** → 다형성
	- 결과적으로 재사용성, 유지보수성, 확장성을 높임


#### 2. 4대 특징

1. **캡슐화 (Encapsulation)**
	- 정의: 데이터와 함수를 하나로 묶고, 외부에는 필요한 인터페이스만 노출하며 내부 구현은 숨기는 것
	- 초점: **접근과 책임의 통제** (멤버 변수는 멤버 함수 내부에서 관리할 것, 외부에서 관심을 두지 않아도 되고, 함수 호출만 하면 됨)
	- 방법: private/protected로 멤버 변수를 감추고, public 함수로만 외부 접근 허용
	- 효과: **결합도 감소** (객체 내부 구현이 바뀌어도 외부 코드에 영향이 없음) → 유지보수 용이

2. **추상화 (Abstraction)**
	- 정의: 복잡한 내부 구현은 감추고, 필요한 핵심 기능만 인터페이스로 드러내는 것
	- 초점: **복잡성의 단순화** (복잡한 건 객체 내부에서 처리할 테니, 외부에선 호출할 기능만 알면 됨)
	- 방법: 추상 클래스(순수가상함수 포함), 인터페이스 역할의 클래스
	- 효과: 복잡성 감소 
		- 학습/사용 비용 감소: 사용하는 쪽은 인터페이스만 알면 됨 (내부 구현 몰라도 됨)
		- 결합도 감소: 내부 구현이 바뀌어도 인터페이스만 유지되면 사용하는 쪽 코드는 영향 없음 (캡슐화와 겹침_)
		- 확장 용이: 인터페이스만 지키면 새로운 구현체를 계속 추가 가능 (다형성과 연결)
		- 결과적으로 유지보수성과 개발 생산성 향상
	- 캡슐화와 차이: 캡슐화는 누가 접근할 수 있는가를 통제하는 것, 추상화는 무엇을 보여줄 것인가를 설계하는 것. 다만 둘 다 결과적으로 외부가 내부 구현에 의존하지 않게 하여 결합도를 낮추고 유지보수를 쉽게 한다는 점에서 공통점.
	- 예시:
		- 게임 엔진을 사용할 때, 개발자는 물리 연산이나 렌더링 파이프라인 내부 구현을 몰라도 `RigidBody.AddForce()`, `Mesh.Draw()` 같은 함수를 호출해서 조립하는 방식으로 로직을 짤 수 있음. 엔진을 만드는 것 자체가 추상화 계층을 설계하는 작업이라 볼 수 있음.
		- EventSystem을 예시로 들면, 구독하는 쪽과 발생하는 쪽은 `Subscribe` / `Publish`라는 인터페이스만 알면 됨. 내부적으로 `weak_ptr`로 구독자 생존 여부를 어떻게 관리하는지, 서로 다른 타입의 콜백을 어떻게 저장하는지, 죽은 구독자를 언제 정리하는지 같은 복잡한 구현은 전혀 몰라도 됨. 이 시스템의 핵심 목적 자체가 "발생자와 구독자가 서로의 존재를 몰라도 되게 디커플링하는 것"인데, 이게 가능한 이유가 바로 `Publish` / `Subscribe`라는 추상화된 인터페이스 덕분

3. **상속 (Inheritance)**
	- 정의: 기존 클래스(부모/베이스)의 속성과 기능을 새로운 클래스(자식/파생)가 물려받는 것
	- 목적: **코드 재사용**, 공통 기능을 부모에 정의하고 자식은 차이점만 구현
	- 주의점: 상속을 남발하면 계층이 깊어져서 오히려 유지보수 어려워짐 → is-a 관계가 명확할 때만 사용
	- 관련 개념: 상속 vs 컴포지션

4. **다형성 (Polymorphism)**
	- 정의: **같은 인터페이스**로 서로 다른 객체가 서로 **다르게 동작**하는 것
	- 종류:
		- 컴파일타임 다형성: 함수 오버로딩, 연산자 오버로딩 (정적 바인딩)
		- 런타임 다형성: 가상함수를 통한 오버라이딩 (동적 바인딩, vtable/vptr)
	- 효과: 부모 타입 포인터/참조로 자식 객체를 다루면서 각기 다른 동작을 실행 가능 → 확장에 유연
